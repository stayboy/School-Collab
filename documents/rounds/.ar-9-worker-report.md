## Deviations (recorded, not silent)

1. **Repository surface extended beyond the doc's file list.** `ISubmissionRepository`/`SubmissionRepository` gained `Add(SignatureEvent)`, `GetSignatureEventByAssignmentStudentAsync`, `ListSubmissionEntitiesByAssignmentAsync`, `ListRecipientEntitiesByAssignmentAsync`, `ListVersionsForSubmissionIdsAsync` (required by the sign-off commands/queries + the status projection). Six pre-existing fake repositories in `Assignments.Tests.Unit` received stub implementations.
2. **No `SignOffStateDto.Finalized` member.** The contract enum is exactly `None`/`AwaitingSignature`/`Signed` per the doc's "do NOT store the full chain enum" note; the *Finalized* state is derived from `FinalizedAt` on the row/context (labels + badge mapping take the full row, not just the enum).
3. **FluentBadge mapping remapped.** FluentUI 4.14.2 render-validates `Appearance` to `Accent`/`Neutral`/`Lightweight` (Outline/Warning/Success throw at render — the WS-A2 documented deviation). The doc's "warning / success / accent" mapping is therefore `Lightweight` (Awaiting) / `Accent` (Signed) / `Neutral` (Finalized); reason recorded in code comments.
4. **Render gate lives on the tab, not just the section.** `Detail.razor` wraps the `<FluentTab>` in `@if (_item.RequiresSignature)` so an assignment without a signature renders no trace of the card (an always-present tab label would contradict "renders NOTHING"). `OnChanged` is left at its optional default — the section reloads itself after each action (the plan's binding note).
5. **`CreateStudentSubmissionCommandHandlerTests` does not exist in the repo.** The additive submission-trigger tests were added to the existing `CreateStudentSubmissionScoringHandlerTests` (same handler under test). Test method names match the binding list exactly.
6. **New test-only `PackageReference`.** `Microsoft.AspNetCore.Mvc.Testing` was added to `SchoolCollab.Assignments.Api.Tests.Unit.csproj` so `SignOffRoutesTests` can run against a **minimal in-process TestServer** host (only `MapAssignmentEndpoints` + mocked handlers; `Program` is never started, so no Postgres/RabbitMQ/Testcontainers). The version is already centrally managed for the `*.Tests.Integration` projects — **CPM/Directory.Packages.props is unchanged (zero new versions)** — but the doc's "ZERO packages" constraint did not anticipate a new reference in this project; the alternative (a new `Assignments.Tests.Integration` project) was larger and was rejected.
7. **Reassign dialog uses the shared `FormRow` primitive** (dialog-ui skill §5) instead of the raw `form-row`/`form-label`/`form-input` divs (those classes are not global — inert outside their owning component).
8. **Decision (h) styling.** `SignOff.razor` / `SignOffSection.razor` use only app.css global utilities + plain semantic markup; references to non-global classes (`section-title`, `recipients-table`, `title-row`, `page-title`) were removed. Two functional fixes rode along: `FluentRadio` values now use Razor expressions (`@SignatureTypeDto.Typed`) instead of string literals (the initial rewrite's binding was a no-op), and the signed+finalized label/badge now maps to "Finalized".
9. **`@implements IDisposable`** added to `SignOffSection.razor` (repo convention).
10. **Test-only cleanups:** duplicate `using` removed in `AssignmentSubmissionSignOffTests`; `FakeStudentDirectory.GetStudentNameAsync` nullability fixed in `SignOffSubmissionCommandHandlerTests` (CS8619/CS8604).
