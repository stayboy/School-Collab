## Plan

### Goal

Execute workstream **WS-A4** (implementation-details §2, round log §3 row 7; spec §3.1): a teacher duplicates any existing assignment — Draft, Published, Scheduled, Closed, or Archived — as a **fresh Draft template copy**. One command (`DuplicateAssignmentCommand`) + handler, one route (`POST /assignments/{id}/duplicate`), one ApiClient method (`DuplicateAsync`), two UI actions (Index row action + Detail button), tests. The copy carries the source's scalar fields + questions/options (with re-pointed `CorrectOptionId`), attachments, modules, and resources; it carries **no** reviews, recipients, gates, submissions, activity-group links, approval stamps, or publish stamps. No migration (zero schema change).
