   precedent). FIX 5 could not be applied literally: the Worker references only
   `SchoolCollab.Assignments.Core`, and Core must not reference `Settings.Core`. Consequence: the moved
   class's XML doc + the null-resolver doc now describe one implementation shared by both hosts, and the
   FIX 3 filter is fixed exactly once.
2. **Wire mirror scope** — `TenantNotificationTemplatePayload` carries `Id`/`Subject`/`Body` only. Kind and
   Channel are the request's own URL keys and are not consumed by the resolve path, so mirroring them would
   be dead fields.

   comment and the spec §3.2 rationale.
4. **`Build*Html` removal** — four dead methods removed rather than kept beside the new preview-shape
   bodies; the one non-test caller (`SweepNotificationQueuer`) never used them.
5. **Pre-existing staged entry** — `git diff --cached` lists one deletion
   (`src/SchoolCollab.Admin.Shared/Components/RichText/RichInstructionSanitizer.cs`) that was already
   staged before this pass; this pass staged nothing and did not touch the index.
6. **`{{Description}}` treated as authored markup** — per the FIX 2 instruction. Note the assignment
   `Description` field is an author summary (not the rich `Instructions`); it is still re-sanitized with the
   composed body, so no markup can escape the allow-list either way.
